# TinyPyk Space Explorer · facilitator guide

Space Explorer is an independent Python pathway for mixed-experience Harrow Code Club sessions. It does not change or erase progress in the original 17-level TinyPyk learning map.

## Course structure

| Path | Mission | Python idea |
| --- | --- | --- |
| Module 1 · Space Cadet | Hello, Explorer | print() |
| Module 1 | Meet Your Astronaut | input() and variables |
| Module 1 | Choose Your Planet | if / else |
| Module 1 | Countdown to Launch | repeat / loop |
| Module 2 · Mission Commander | Meet Functions | def and call |
| Module 2 | Reuse a Helper | call a function twice |
| Module 2 | Pass a Planet | functions with parameters |
| Module 2 | Two Planet Missions | reuse with different arguments |
| Final project | Build Your Space Mission | apply all the above |

### Supporting mixed-ability groups

- New joiners start Module 1 independently or with a volunteer.
- Returning learners can choose **Start Module 2** early without waiting to complete Module 1; all missions in both modules are still needed for the final certificate.
- Space Explorer Blockly drafts are saved on this device when learners press Play or navigate between missions.
- Children may revisit completed missions to improve code.
- Each mission includes starter Blockly code; ask learners to change it rather than merely press Play.
- Ask children to use invented astronaut nicknames, never real personal details.

### Final project checklist

1. Ask for an invented astronaut nickname and a planet.
2. Use an if/else decision for two different results.
3. Repeat a launch check with a loop.
4. Define and call a function.
5. Test with two different planet answers, debug, and ask a volunteer for review.
6. Print a certificate using the browser's Print / Save as PDF option.

The project only marks complete after **two successful code runs** and lightweight structural checks pass. A mentor should still check that both paths worked. Certificate printing includes an on-device review checkbox. The certificate name is neither saved nor sent to the server.

### Important limitations

- Coding checks look for language constructs in successfully executed Python, not perfect solutions or genuine understanding.
- Completion progress is stored in this browser's localStorage; clearing site data, using another device or private browsing may erase it.
- No central certificate registry or cryptographic verification exists.
- The certificate is a classroom achievement, not an accredited qualification.
- No child account, real name or identifiable information is necessary.
- Use TinyPyk's existing Save to computer action to save work-in-progress code before closing the browser.
- Existing Python levels, save/load, code execution and admin settings remain unchanged.
